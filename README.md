# Admin Dashboard

## Описание проекта
Admin Dashboard - это полноценное веб-приложение для управления пользователями с современным интерфейсом. Проект разработан на React с использованием функциональных компонентов и хуков.

## Технологии
- React 19
- React Router v7
- React Hooks (useState, useEffect, useContext)
- Axios для работы с API
- React Hook Form + Yup для валидации
- React Hot Toast для уведомлений
- Recharts для графиков
- Bootstrap 5 для стилизации
- JSON Server для mock API

## Функциональность

### Авторизация
- Регистрация новых пользователей
- Вход существующих пользователей
- Хранение токена в localStorage
- Защищенные маршруты
- Разграничение ролей (Admin/User)

### Управление пользователями (CRUD)
- Просмотр списка пользователей
- Просмотр деталей пользователя
- Добавление нового пользователя
- Редактирование пользователя
- Удаление пользователя

### Дополнительные функции
- Поиск пользователей по имени/email
- Фильтрация по роли (Admin/User)
- Сортировка по всем колонкам
- Пагинация (5 пользователей на страницу)
- Темная/светлая тема
- Сохранение настроек в localStorage
- Графики и статистика на Dashboard
- Admin Panel для управления ролями
- Отслеживание последнего визита
